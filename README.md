# SDS App

Prisberegner og planlægningssystem udviklet som praktikprojekt på Datamatikeruddannelsen.

## Teknologier

- Node.js
- Express
- MongoDB Atlas
- Mongoose
- HTMX
- EJS

## Funktioner

- Prisberegning
- Rengøringsplaner
- Lokaler og opgaver
- PDF-generering
- Drag-and-drop editor
- Brugerhåndtering
